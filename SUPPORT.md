# Support

## Usage questions

Use GitHub Discussions for setup questions, architecture questions, adapter experiences and ideas that are not yet concrete bugs.

Before asking, run:

```bash
bar doctor --json
bar agents --json
```

Share the relevant non-secret output plus:

- BAR commit or release
- operating system
- Node version
- selected Builder/Reviewer adapters
- exact command that failed
- the error message

Never post credentials or private project data.

## Bugs

Open an Issue when you can describe a concrete BAR defect or reproducible behavior gap. Include the smallest synthetic reproduction possible.

## Security vulnerabilities

Do **not** open a public issue with exploit details. Follow [SECURITY.md](SECURITY.md).

## Feature ideas

Start with a Discussion when the design is still broad. Open an Issue once the problem, boundary and acceptance criteria are clear.

## No SLA

BAR is community open source. There is no contractual support SLA.
